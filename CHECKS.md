# Initial checks

## python.shell-true

- Severity: critical
- Category: security
- Recommendation: Pass an argument list with shell=False.

## python.unsafe-yaml

- Severity: high
- Category: security
- Recommendation: Use yaml.safe_load or SafeLoader.

## python.tls-disabled

- Severity: high
- Category: security
- Recommendation: Keep TLS verification enabled.
